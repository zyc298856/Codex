### P1-6：5.8 节 RGA 加速效果解释补充

**位置**：第五章 5.8 节 Zero-copy 输入路径探索

**需要做的事**：在 RGA 实验结果的讨论中，补充更充分的技术解释：

> RGA 硬件预处理的加速效果需要在完整硬件流水线中才能充分体现。RGA 的优势在于与 MPP 硬件解码器配合，使用物理连续内存避免 CPU 拷贝。当前实验使用 OpenCV 读取已解码视频帧，数据位于 CPU 虚拟地址空间，RGA 仍需将数据从 CPU 内存搬运至自身可访问的缓冲区，该搬运开销抵消了硬件计算节省的时间。只有在"解码→RGA 预处理→NPU 推理"全链路使用物理连续内存的完整流水线中，RGA 才能发挥真正的零拷贝优势。本文的 RGA letterbox 验证实验已确认检测结果与 OpenCV 完全一致（9,352 vs 9,352），证明 RGA 功能正确；完整零拷贝链路的集成作为后续优化方向。
